# ぼぶる

トレードの計画・記録・分析・ルールブックを1つにまとめた、単一HTMLのWebアプリ。
依存ライブラリなし・ビルド不要。`index.html` をブラウザで開くだけで動きます。

## 機能

- **ホーム** — 口座残高と推移、本日の損益/R/回数、連勝連敗、Fintokei の目標・日次損失・全体損失メーター
- **計画** — エントリー前に価格・SL・TP・ロットを入力すると、予定損失/利益・リスク率・RR・推奨ロットをライブ計算。「この損切りを食らったら残り枠がどうなるか」も表示
- **トレード** — 保有中 / 計画中（下書き）/ 決済済み / 取消 の一覧と編集、決済登録
- **成長** — 期間別の勝率・PF・純R・最大DDなどの集計、累積損益/累積R/残高推移のグラフ、パターン別・環境別の分類集計
- **ルール** — フォルダ分けしたルールブック（変更履歴つき）と、仮説を検証する「研究」機能
- **設定** — 口座・内部リスク基準・Fintokei公式ルールの数値・テーマ

## データの扱い

- 記録は `localStorage` にこの端末だけで保存されます（サーバーへは送りません）
- スクリーンショットは別ストアに保存され、同期・バックアップの対象外です
- 端末間の移動は設定タブの**同期コード**（丸ごと上書き）で行います
- JSONバックアップ / 復元、CSV書き出しに対応

## 使い方

`index.html` を開くだけ。スマホではホーム画面に追加するとフルスクリーンで使えます。
