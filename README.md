# ぼぶる

トレードの計画・記録・分析・ルールブックを1つにまとめた、単一HTMLのWebアプリ。
依存ライブラリなし・ビルド不要。`index.html` をブラウザで開くだけで動きます。

## 機能

- **ホーム** — 口座残高と推移、本日の損益/R/回数、連勝連敗、今日の環境認識の要約、Fintokei の目標・日次損失・全体損失メーター
- **環境** — その日の Morning Brief。日足/4H/1H/15M の方向、現在価格と EMA 10/75/200、前日高安・週足高安・直近高安・主要サポレジ、アジア/ロンドン/ニューヨークのセッション別高安、経済指標（時刻・重要度）、今日の見方（ロング優勢/ショート優勢/様子見）、Bull / Bear / No Trade シナリオ、要約と市場材料メモ。1日1件で、その日に保存したトレードへ自動で紐付きます
  - **朝分析** ボタンで市場データを取り込めます。取り込んだ内容は編集してから保存します
  - 取得先はまだ「未接続」（手入力）と「デモ」だけ。差し替え口は `marketDataProvider` にまとめてあります → [docs/phase1-morning-analysis.md](docs/phase1-morning-analysis.md)
  - セッション時間は `Asia/Tokyo` / `Europe/London` / `America/New_York` のタイムゾーンで計算するので、サマータイムに自動で追従します
- **計画** — エントリー前に価格・SL・TP・ロットを入力すると、予定損失/利益・リスク率・RR・推奨ロットをライブ計算。「この損切りを食らったら残り枠がどうなるか」も表示
- **トレード** — 保有中 / 計画中（下書き）/ 決済済み / 取消 の一覧と編集、決済登録。銘柄・方向の隣に RR を表示します
- **成長** — 期間別の勝率・PF・純R・最大DDなどの集計、累積損益/累積R/残高推移のグラフ、パターン別・環境別の分類集計
- **ルール** — フォルダ分けしたルールブック（変更履歴つき）と、仮説を検証する「研究」機能
- **設定** — 口座通貨・内部リスク基準・Fintokei公式ルールの数値・為替レート・テーマ

## 口座通貨

XAUUSD のような USD建ての銘柄は損益が USD で出ます。口座通貨が JPY のときは
USDJPY を自動取得して、予定損失・予定利益・リスク率・推奨ロットを口座通貨で計算します。

- レートは無料の公開レート（キー不要）を10分キャッシュで取得します。**更新は1日1回**なので、日中の変動は反映されません
- 取得できないときは手動レート、それも無ければ 1 で計算し、画面にその旨を出します
- レートはエントリー時の値をトレード記録に焼き込むので、あとでレートが動いても過去のリスク率と R は揺れません
- 詳しくは [docs/fx-rate.md](docs/fx-rate.md)

## データの扱い

- 記録は `localStorage` にこの端末だけで保存されます（サーバーへは送りません）
- スクリーンショットは別ストアに保存され、同期・バックアップの対象外です
- 端末間の移動は設定タブの**同期コード**（丸ごと上書き）で行います
  - 取り込みは丸ごと上書きなので、アプリを更新したときは**両方の端末で一度リロードしてから**同期して下さい
- JSONバックアップ / 復元、CSV書き出しに対応

## 使い方

`index.html` を開くだけ。同じファイルがPCとスマホの両方に合わせて表示を変えます。

- **スマホ**（横幅900px未満）— 下部タブ。ホーム画面に追加するとフルスクリーンで使えます
- **PC**（900px以上）— 左サイドバー。本文が広くなり、グラフも大きくなります
- **広い画面**（1180px以上）— ホームは指標が横1列＋環境認識とFintokeiが左右に、成長はグラフと集計表が2列に並びます

## 開発

回帰テスト（任意）。実ブラウザで保存・同期・復元・計算・レイアウトを確認します。

```
npm i -D playwright && npx playwright install chromium
node tests/run.mjs
```

アプリ本体は依存ライブラリなしのままです。playwright はテストを走らせるときだけ必要です。
