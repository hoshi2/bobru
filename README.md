# ぼぶる（Trade OS）

トレードの環境認識・シナリオ・記録・分析・ルールブックを1つにまとめた、単一 HTML の Web アプリ。
依存ライブラリなし・ビルド不要。`index.html` をブラウザで開くだけで動きます（PC とスマホで表示が変わります）。
公開版：https://hoshi2.github.io/bobru/

## 画面（2026-09-24 の作り直し後）

- **今日** — 数字タイル（口座残高・本日の損益・本日のR・勝率30日・連勝連敗・区切りまで）、環境認識（見方・各時間足の向き・前日高安・価格と EMA75/200 の位置・紫の状態・要約・ロング案／ショート案／見送り条件・重要指標）、保有中、口座の状況（目標・自分の日次停止・規約の損失枠のメーター）
- **シナリオ** — 価格・SL・TP・ロットを入れると右に予定損失／利益・リスク率・RR・推奨ロット・「この損切りで残り枠がどうなるか」をライブ計算。根拠（4H 環境・紫ライン・トリガー・EMA・クロス時の水色・紫の広がり）を3秒で押して記録
- **記録** — 保有中／下書き／決済済み／取消。PC は表（行を押すと詳細）、スマホはカード。決済登録では理由・逸脱・感情・学びを残す
- **分析** — 期間と「この口座／全体」で切替。統計タイル、累積損益・累積R・残高推移の線グラフ、月曜始まり・週の枠つきカレンダー、分類別の集計表（パターン・4H・紫ライン・EMA・クロス時の水色・紫の広がり・トリガー・決済理由・保有時間・逸脱…）
- **設定** — 口座（複数。ルール・通貨・終了）、計算、内部ルール、為替レート、取引履歴の取り込み（MT5 レポート／cTrader CSV）、表示、版番号、端末間の同期、データ（バックアップ・復元・CSV・削除）

## 朝の環境認識（自動）

平日 7:30（日本時間）にクラウドの Claude Code（ルーチン）が動き、`tools/asa/` のスクリプトで値動き（COMEX 金先物 GC=F をスポットに合わせてずらしたもの）から各時間足の向き・EMA・節目・BOB EDGE v1.8 の値を計算し、TradingView から現在値・前日高安・今週高安・経済指標を取り、AI がシナリオ2本＋見送り条件を書いて `briefs/latest.json` を push します。
アプリは起動時と画面に戻ったときに `briefs/latest.json` を見に行き、今日の環境認識が空なら自動で入れ、手で書いてあれば「反映」ボタンを出します。手順書は `.claude/skills/asa/SKILL.md`（Claude Code で `/asa` または「朝」）。

- `briefs/` は公開ページから誰でも読めます。口座・残高・取引の記録は入れません
- AI の見方（`aiBias`）と自分の判断（`bias`・メモ）は別に保存されます

## 口座と通貨

口座は複数持てます（JPY／USD）。XAUUSD のような USD建て銘柄は、口座通貨が JPY なら USDJPY を自動取得（無料の公開レート、更新は1日1回）して換算します。レートはエントリー時の値を記録に焼き込みます。口座の通貨を変えると、その口座の記録の通貨表示も揃えます。詳しくは [docs/fx-rate.md](docs/fx-rate.md)。

## データの扱い

- 記録はブラウザの `localStorage` にその端末だけで保存（サーバーへは送りません）。データ版は 3
- 端末間の移動は設定の同期コード（丸ごと上書き）。JSON バックアップ／復元、CSV 出力あり
- 取引履歴の取り込みは、保有中の計画に紐付けるか計画なしの記録にするかを1件ずつ確かめ、取引 ID で二重を防ぎます
